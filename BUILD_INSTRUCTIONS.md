# Checking and submitting gmediation to CRAN

Run these steps from the package root in R, in order.

```r
install.packages(c("devtools", "roxygen2", "testthat", "covr", "knitr",
                   "rmarkdown", "mediation", "MASS", "writexl", "gridExtra",
                   "ggplot2"))

devtools::test()                       # unit tests (set NOT_CRAN=true for all)
roxygen2::roxygenise()                 # regenerates NAMESPACE and man/*.Rd
devtools::check(args = "--as-cran")    # needs internet for the incoming checks
devtools::check_win_devel()            # win-builder (R-devel, Windows)
devtools::check_rhub()                 # optional: other platforms
```

Then build the tarball and submit it at <https://cran.r-project.org/submit.html>:

```r
devtools::build()                      # creates gmediation_2.0.0.tar.gz
```

Before submitting:

1. Fill in the `[[...]]` placeholders in `cran-comments.md` (reason for the
   2020 archival, test environments and check results).
2. Confirm `Authors@R` / maintainer e-mail in `DESCRIPTION` is an address you
   can receive mail at (CRAN confirms by e-mail).
3. Note that `R CMD check` examples run `\donttest{}` code only with
   `--run-donttest`; the `gmedsens()` example takes about 1.5 minutes.

## Layout

```
DESCRIPTION  NAMESPACE  NEWS.md  README.md  cran-comments.md  DEVELOPMENT.md
R/           gmediate.R  gmedsens.R  setup.R  simulate.R  summarise.R
             engine-gmediate.R  engine-gmedsens.R  tables-*.R  plots-gmedsens.R
             print-*.R  export.R  dental-data.R  gmediation-package.R
man/         generated by roxygen2
data/        dental.rda   (built from data-raw/dentex.csv by data-raw/dental.R)
data-raw/    dentex.csv  dental.R           (not included in the package build)
vignettes/   gmediate.Rmd  gmedsens.Rmd  and the two figures of gmedsens.Rmd
tests/       testthat.R  testthat/  (unit, snapshot and golden regression tests)
```

See `DEVELOPMENT.md` for the function-level layout and the test strategy.
